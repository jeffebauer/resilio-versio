# 0038 — Wellspring fit round 3: four tank fixes, one at a time

**Status:** Accepted, 2 Oct 2026: the owner picked **voicing 7, "+ gentler"** (round 4's F, "plus gentler") on the clicks, hits and skank rows: "Overall liking 'plus gentler'". 7 is the default sound; 0–6 stay as Renderer-only references (`tank_voicing`). See "Decision" at the end for what shipped and what it took. (Proposed 2 Oct 2026 on `proto/wellspring-fit-3`, round 4 on `proto/wellspring-fit-4`; the rounds are kept below for the history. Numbers, method and gates: `docs/m8-tuning-backlog.md` "Wellspring fit round 3", "round 4" and "Wellspring F merge"; scripts `docs/prototypes/wellspring-fit-3/`, `-4/`.)

**Context:** The owner, listening to their Wellspring next to our closest knob settings (2 Oct 2026, `renders/wellspring_fit2/page/`): the Wellspring "sounds more diffuse"; ours has "more low end/mids which makes it feel more present and forward, whilst the Wellspring sounds further away and gentler in tone"; "Wellspring repeats diffuse faster whilst ours flicker back and forth from left to right — sounds more delay-like rather than reverb-like". Measured on the click take at the closest settings (2 Springs, TENSION 0.875, TONE 0.8, CLEAN, SPLASH 0, WOBBLE noon, DRIVE 0.25), Wellspring vs ours: echo density at 300–500 ms 0.97 vs 0.66; tail low-mid balance −6.0 vs −1.7 dB; the L/R balance jumps 2.8 vs 10.2 dB every 10 ms, L/R envelope correlation 0.95 vs 0.51. In the previous round (`proto/wellspring-fit`, 30 Sep) the owner picked **B, the fitted Sweep**, and dropped C's tone dip.

Why ours flickers: in 2 Springs the side signal is k·(A − B), so the left output is mostly Spring A and the right mostly Spring B; their Loops have different lengths, so each echo lands in one ear, then the other.

**Decision (proposed): one of five voicings, each adding one fix to the one before** (`core/params/TankVoicing.h`):
- **0 = today.**
- **1 = Sweep:** B's Sweep, re-fitted on today's tank (B was fitted on the smooth-arc tank, whose Loop fC was higher). One chain of "highs later" allpass sections in front of every Spring, shared: 40 sections at noon, top 0.85 × the Loop's fC, a 0.35 (the fit returned B's own numbers: 41, 3.6 kHz, 0.37). The Loops keep fewer sections (B's shares), so the worst case costs what it costs today; B's high path (crossover 0.36 × fC, its pickup lined up on the Loop's first echo + 3.7 ms). The pickups move back by the Sweep's delay, so the first echo's body keeps its time (ADR 0029).
- **2 = 1 + stereo together:** no Spring is panned (side 0); both outputs hear every Spring; the width comes from the decorrelator D alone (w 0.85), which cancels exactly in mono (SpringModes.h), with D's bass taken out below 150 Hz.
- **3 = 2 + diffusion:** three short allpasses (0.85 / 1.45 / 2.15 ms, c 0.2, scaled per Spring) on each Loop's feedback after the pickup, so each trip smears the echo more; L shrinks by their delay (echo spacing unchanged); the first echo never passes them.
- **4 = 3 + gentler:** a low cut in front of the Springs (high-pass 260 Hz, −3 dB shelf at 600 Hz), Loop damping × 1.5, the high path's T60 0.7 × DECAY (was 0.45).

**Measured** (closest settings, DECAY re-fitted per voicing to the Wellspring's 3.13 s; Wellspring / 0 / 1 / 2 / 3 / 4): echo density 300–500 ms 0.97 / 0.66 / 0.67 / 0.67 / 0.96 / 1.02, 100–200 ms 0.77 / 0.64 / 0.70 / 0.70 / 0.83 / 0.88; tail low-mid balance −6.0 / −1.7 / −1.8 / −1.8 / −1.9 / −5.9 dB; L/R jump 2.8 / 10.2 / 9.3 / 1.2 / 1.6 / 1.6 dB; envelope correlation 0.95 / 0.51 / 0.58 / 0.98 / 0.98 / 0.98; T60 250 Hz–4 kHz Wellspring 4.66 / 3.83 / 3.27 / 2.68 / 1.88 s, today 3.29 / 3.48 / 3.14 / 2.22 / 1.04, 4: 3.76 / 3.59 / 3.34 / 2.60 / 1.18; echo spacing 40–41 ms throughout (Wellspring 36); first arc at 3.56 / 4.49 kHz 0.6 / 0.2 ms today, 7.3 / 7.7 with the Sweep (Wellspring 7.7 / 15.1).

**Not done:** lows longer than DECAY asks (the Wellspring's 250 Hz octave rings 4.7 s): a Loop low shelf with the gain design allowing 1.5 × T60 below 250 Hz broke AntiRes layer 1 and stretched DECAY 1 to 12 s (ADR 0001), so it was dropped; the top octave stays short (the Loop's fC low-pass).

**Consequences:**
- Default 0: renders and the firmware's DSP code, Tank object and pool are today's (+8 B of flash); the full suite passes. The firmware compiles only its default voicing (`RV_TANKV_BUILT`, `RV_FIXED_VOICINGS`).
- All five versions pass the M6 grid (0 Ringing flags, Howl 54/54) and the new `test_tank_voicing` (stability, first-echo time, together and wide, mono sum, echo density).
- If the owner picks 1–4, `kDefaultVoicing` changes and the checks the backlog lists as failing with that voicing as default need fixing or re-reading before it ships: WOBBLE's left/right ratio (1–4), the aliasing floor at DRIVE 1 (1–3), SPLASH audibility on a rimshot (1–2), a few marginal level/limiter checks, and 4's lost level (a makeup like the Big Knob's).
- Cost: the worst case stays the worst case (155 vs 156 Chirp sections); ~+1 point on the chip with the diffusers; noon gets ~28 more sections. Pool 28,719–29,386 of 30,000 floats. Flash as if picked: profile 127,700 B (1) to 130,004 B (4, 99.2 % of 128 KB).

## Round 4 (2 Oct 2026, branch `proto/wellspring-fit-4`; still Proposed)
**Context:** on round 3's page the owner heard the Wellspring "more muted with less highs and a wider stereo field", its repeats darkening "whilst our repeats sound more metallic and bright", and its echoes further apart. The echo spacing was a settings error (round 3 compared at TENSION 0.875; the corrected closest settings are TENSION 0.5, TONE 0.7). The rest is the tank: at every knob setting that keeps the tail's balance, our first 60 ms after a click carry ~17 dB more top than the Wellspring's (−9 vs −25.7 dB above 4 kHz re 200 Hz–4 kHz), and the Wellspring's sweep (take D, `tools/sweep_ir.py`) falls −6 dB at 2.5 kHz and ~20 dB/oct above, ours −2.4 dB/oct. A real tank's driver coil and pickup magnet both lose treble, so every echo is filtered twice and is gentle from the start; ours was flat at both ends and darkened the tail with Loop damping instead.

**Decision (proposed): three more voicings on top of round 3's 3** (`TankVoicing.h`; 0–4 unchanged):
- **5 = 3 + transducers:** a resonant low-pass on what enters the Springs (2.35 kHz, Q 1.0, after the Clang; the Kick's knock bypasses it) and on the wet before DriveOut (4.5 kHz, Q 0.67); inside the tank the highs lose less (Loop damping × 3.6, high path T60 1.5 × DECAY's, level × 0.9); the coil's even-order colour (a level-eased square term: 2nd harmonic −25 dB like the Wellspring's); the wet −2.5 dB.
- **6 = 5 + wide again:** the Springs' difference back, through its own decorrelator D2, into the same bass-cut difference as D (L = mid + X, R = mid − X): width without the flicker; mono still exactly the mid.
- **7 = 6 + gentler:** round 3's low cut re-fitted to the sweep's bass (high-pass 220 Hz, −3 dB shelf at 300 Hz), with a level makeup (power into / out of it).

**Measured** (closest settings, DECAY re-fitted; Wellspring / 0 / 3 / 5 / 6 / 7): onset −25.7 / −9.2 / −10.2 / −25.7 / −25.7 / −24.6 dB; repeat darkening −7.7 / −12.9 / −13.3 / −6.5 / −6.5 / −6.6 dB; 4 kHz T60 1.88 / 1.08 / 0.92 / 1.58 / 1.58 / 1.59 s; tail L/R corr −0.04 / 0.01 / 0.17 / 0.16 / −0.04 / −0.05 (L/R jump 2.8 / 9.5 / 1.5 / 1.5 / 1.3 / 1.3 dB); low-mid balance −6.0 / −0.9 / −1.1 / −3.9 / −3.9 / −6.7 dB; sweep corner 2.5 / 3.2 / 4.0 / 3.2 / 3.2 / 3.2 kHz, slope −20 / −2.4 / −3.0 / −25 / −25 / −25 dB/oct; 2nd harmonic −25 / −40 / −40 / −25 / −25 / −25 dB. Full table and gates: `docs/m8-tuning-backlog.md` "Wellspring fit round 4"; scripts `docs/prototypes/wellspring-fit-4/`; page `renders/wellspring_fit4/compare/`.

**Consequences:** default 0 is bit for bit today's (renders `cmp`-identical; firmware ±8 B codegen). 5–7 pass the M6 grid (0 flagged, steady_tone 0 after the wet trim, Howl 54/54) and `test_tank`'s stereo checks. If one is picked: TONE's dark half becomes much less dark (the damping scale; needs re-mapping), levels move (hits −1.4, pad −5 dB vs today), the SPLASH crash is darker (two `test_m7_tank` SPLASH checks miss by a hair), and the remaining as-if failures listed in the backlog need fixing or re-reading. Pool 29,821 of 30,000 floats for 6 and 7. Flash: the release build fits (7: 126,176 B), the profile build overflows the 128 KB internal flash by 1.3–3.1 KB (5–7).

## Decision (2 Oct 2026)

- **`tankv::kDefaultVoicing = kGentleWide` (7).** The plugin and the firmware play it; the firmware builds 7's parts (`RV_TANKV_BUILT` 7) and, its voicing being a constant, none of the other voicings' branches. 0–6 stay as Renderer-only references, as for TONE, SPLASH, WOBBLE and SPRINGS 3. SPRINGS 3 stays coupled (ADR 0037), now on 7's tank: the coupled Loops carry 7's feedback diffusers and pickup, and "today's repeat timing" (ADR 0037 round 2) is 7's own.
- **What it took to ship.** With 7 as the default the suite passed 63 % (12 of 19). Every limit stayed where it was. Two kinds of fix, kept apart:

**1. Real problems: the sound changed** (all in 7 only, `tankv::hasShipFixes`; 5 and 6 play as in round 4; numbers in `TankVoicing.h` "7 as shipped"):
- *TONE re-map* (the owner's hero control). Round 4's transducers and Loop damping ×3.6 lifted TONE's dark floor (TONE 0 tail −11.9 dB vs today's −29.2). Now left of noon the tank eases back toward today's: Loop damping ×1 at TONE 0 (×3.6 from noon, eased by (1 − 2·TONE)^0.5), the high path today's short length (0.45 × DECAY, round 4 1.5), a darker input coil (1.8 kHz, round 4 2.35). The darker tank takes level, so it gives it back by what the material has to lose (1.6 × the dB a 500 Hz low-pass takes from the input, up to 9 dB): a snare comes back about as loud as at noon, a held pad isn't pushed at the limiter (a fixed +5 dB did that: pad 3.5, organ 4.7 dB of limiter). Right of noon the Big Knob is today's; the output pickup opens toward 9 kHz on a steep curve ((2·TONE − 1)^4), so TONE 0.7 (the owner's F) moves < 0.1 dB.
- *The coil's even-order term* is high-passed (25 Hz at noon, rising to 250 Hz with the Big Knob): it keeps the doubled frequencies and drops the difference tones between them, which the Springs rang in their loudest low notes. TONE fully right thinned the lows only −5.5 dB (test_drive's bar −8); now −18.6 / −20.4 / −14.0 dB (CLEAN / DRIVEN / KICKED).
- *DRIVE's loudness curve* (KICKED grew +8.2 dB across DRIVE, designed +6 ± 2). Three causes, three fixes: the low cut's makeup grew with KICKED's own low products (it now also reads the raw input, before DRIVE, and gives back the smaller of the two); the −2.5 dB wet trim made DRIVE's pickups squash the tail less (the trim now comes after the pickups, so they see today's level); and the coil hid DRIVE 1's grit (KICKED's level-matched DRIVE 0 vs 1 null −6.1 dB, bar ≥ −6). In KICKED the coil now saturates with DRIVE (DRIVE³): its corner opens up to 0.6 octave and it gives up 1.5 dB. KICKED +6.6 dB at DRIVE 1 (today +6.7), CLEAN +6.2, DRIVEN +6.4; KICKED's null −5.5 dB; CLEAN stays mild (−22.6, bar ≤ −15).
- *SPLASH at low DRIVE.* The transducers darken the crash against the tail around it most with DRIVE fully down (SPLASH C's "DRIVE-free" checks: DRIVE 0 and 0.8 3.1–4.3 dB apart, bar 3). The Clang (past its ceiling: a lift under the ceiling was taken straight back) and the Clatter are lifted 4 dB in CLEAN / DRIVEN at DRIVE ≤ 0.5, easing to none by DRIVE 0.8, and 3 dB in KICKED at every DRIVE (a fade there made DRIVE reduce the splash between 0.5 and 0.75). Relative to its own SPLASH 0 the crash is now at least as strong as today's at DRIVE 0 and 0.8 at SPLASH 0.75 and 1; it is darker in colour.
- *The top of DECAY.* Loop damping ×3.6 let 1–2 kHz ring as long as a DECAY-max tail: on SPRINGS 3 coupled a 2.1 kHz tone held (test_springs3 steady tone), and a held tone's tail beat so deeply that WOBBLE's steps read out of order. From DECAY 0.7 the damping scale eases (smoothstep) to ×1.5 at DECAY 1, and WOBBLE's left side (random wow, in the Loops) to ×0.9 there (fully left read 1.61× fully right, bar 1.6; now 1.43). DECAY ≤ 0.7, the picked 0.665 included, is round 4's.
- *Aliasing at DRIVE 1* (round 4: low non-harmonic products −47 to −54 dB) did not fail on this branch after the merge; with the high-passed square term the worst deciding product is −66.9 dB (DRIVEN), −70.2 dB (KICKED, −6 dBFS), bar −60. The square term's difference tones are the likeliest source of round 4's 22–38 Hz products.

**2. Tests whose precondition the intended sound removed: the stimulus or the corner changed, never the bar** (each says so in its comment):
- `test_clicks` held-chord scan must drive the limiter: −9 → −5 dBFS (it reached it at 1 of 31 TENSION settings; today's tank 9; now 7).
- `test_led_meter` red LEDs while the limiter pulls: the −3 dBFS chord into 3 Springs instead of 2 (into 2 it no longer reached the limiter, 0.0 dB; into 3 it pulls 3.3 dB, as 2.7 before).
- `test_sustain_trim` "it is the Sustain trim": the organ instead of the C2 drone in the same cell (the low cut takes the drone's 65 / 131 Hz, so it never reached the limiter with or without the trim); the organ pulls 4.6 dB without the trim, 1.8 with it. "Lets go": the pad at −1 dBFS (at −6 it no longer needed the trim, held −0.3 dB; now −5.0).
- `test_springs3` runs in two passes: the default (coupled) and today's position 3 on tank voicing 7 as shipped; the reference SPRINGS 3 voicings (Renderer-only, built and measured on tank voicing 0) on tank voicing 0, today's baselines included. On 7 several references failed their level / ringing / timing bars (e.g. series 19 dB ringing; pan Chirp first echo +1.0 ms): they were tuned on the other tank and aren't playable.
- `test_tank_voicing` checks the default is 7.

**Result:** ctest 100 % of 19; M6 grid (270 Ringing + 54 Howl cells) 0 flagged, steady tone 0, Howl 54/54; SPRINGS 3 coupled M6 grid 0 of 90, Howl 18/18. The picked sound at TONE 0.7 (01_clicks, closest settings, DECAY 0.665; round 4's F → shipped): onset brightness −24.7 → −24.6 dB, low-mid balance −6.7 → −6.6 dB, L/R jump 1.2 → 1.2 dB, repeat darkening −6.6 → −6.6 dB; hits and skank within 0.5 dB on level, low-mid and top except the skank's top +0.5 dB. TONE's tail brightness at 0 / .25 / .5 / .75 / 1: today −29.2 / −20.2 / −12.1 / −7.4 / +0.2 dB, round 4's 7 −11.9 / −8.0 / −5.0 / −2.4 / +2.9, shipped −30.3 / −16.3 / −5.1 / −2.5 / +5.2.

- **Flash.** 7 and its fixes cost ~10 KB (release 2.6 KB over 128 KB, profile ~10.6 KB over). Firmware only, desktop code unchanged: set-up and per-tick housekeeping built for size (`RV_SIZE_OPT`: every prepare / reset, the pool layout, Splash / Wobble / Kick per-tick parts, the Morph blends); `Tank::process` at -O3 without loop unswitching (it copied the whole input loop for the Clang ceiling's one invariant branch: 1.5 KB); `printf` / `putchar` / `exit` stubs (libDaisy's USB debug logs and crt0's `exit` pulled newlib's stdio in; nothing was retargeted); no `malloc` in the firmware Tank; `exp(log)` for `pow`; profile's report divides in float. Every per-sample path and the knob-move coefficient redesign (`updateBaseSettings`, `updateSpringSettings`, `Spring::prepareTransition` / `prepareDamping` / `setSettings` / `commitDesign`, `DriveIn::set`, `Tilt::set`) stay -O3. Release 126,280 B (96 %), profile 130,496 B (99.6 %, 576 B spare), m0test 82,320 B.
- **CPU: unmeasured on the chip.** 7 adds per sample the Sweep (40 sections at noon; the Loops keep fewer, so the worst case stays the worst case), three Loop diffusers per Spring, the coil and pickup filters, the second decorrelator, the low cut and the makeup followers; the housekeeping is now -Os. Desktop (`test_m7_tank`'s worst case, 3 Springs KICKED, SPLASH / WOBBLE busy): 548 ns/sample vs 545 on today's tank. An M3 run (run 15, this build) is due before a release; run 13 was 66 % peak against 70 %.
- **Not done (round 5):** the owner still hears the Wellspring's transient as softer, its tail's resonance in a different place, and different frequencies centred vs wide. Noted along the way: our onset above 4 kHz already matches (−24.6 vs −25.7 dB), so the softer transient is likelier the echo front below 2 kHz (round 4: echo rise 1.0–1.3 ms vs 9.4); 7 keeps the bass centred below 150 Hz (the decorrelators' bass cut) while the Wellspring's L/R IR correlation is −0.14 over 50 ms–1 s.
